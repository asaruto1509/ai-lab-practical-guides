値上げのお知らせ、角が立たずに書けますか？AIチャットで案内文の下書きを作る方法

値上げ・価格改定をお客様や取引先に伝えるのは、個人店主や中小企業の担当者にとって気が重い仕事です。

記入シートを開く元記事で詳しく読む

このページで確認すること

  • 読み手: 顧客向けか取引先向けか。店頭掲示かメールか。常連か法人か。
  • 改定する対象: 商品名・サービス名・型番・単位。
  • 新旧価格: 現行価格と新価格。税込か税抜か、単位も書く。
  • 適用日: いつから新価格にするか。
  • 理由・背景: 原材料価格、エネルギー費、食材費、光熱費など。主観ではなく、説明できる事実を書く。
  • 感謝と今後: 日頃の感謝、品質維持やサービス改善の姿勢、問い合わせ先。

実践の流れ

  1. 1値上げ案内文、何を書けば角が立たない？
  2. 2準備:値上げの理由・新旧価格・適用日を整理する
  3. 3手順:AIチャットに業種と事情を伝えて下書きを作る
  4. 4具体例:架空の個人店でのプロンプトとAIの返答(※例)
  5. 5完了確認:送る前にチェックすべき5項目
  6. 6失敗時の対応:反発が来た・タイミングを逃した場合の立て直し方
