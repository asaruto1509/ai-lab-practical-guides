Windowsの更新、止まっていませんか？IPAが「至急更新を」と呼びかけた10月の脆弱性を、社内PCの更新確認表と連絡文で点検してみよう

社内のWindows PCは「設定しておけば自動で更新されるはず」と考えている方は多いと思います。

記入シートを開く元記事で詳しく読む

このページで確認すること

  • 2026年10月14日（日本時間）に、Microsoft製品に関するセキュリティ更新プログラムが公表されています。
  • これらの脆弱性を悪用された場合、アプリケーションプログラムが異常終了する、攻撃者によってパソコンを制御される、といった様々な被害が発生するおそれがある、とされています。
  • そのうちCVE-2026-96951の脆弱性について、Microsoft社では悪用の事実を確認済みと公表しており、IPAは「今後被害が拡大するおそれがあるため、至急、セキュリティ更新プログラムを適用してください」と呼びかけています。CVE番号は公式が挙げている表記で、この記事では技術的な中身には踏み込みません。
  • セキュリティ更新は通常自動で行われます。Windows Updateを通じて、セキュリティ更新プログラムや重要な更新が自動的にダウンロードされ、インストールされます。
  • Windows Updateからセキュリティ更新プログラムを確認できます。また、適用には再起動が必要になることがあります。
  • 更新管理を行っている組織は、Microsoft社のセキュリティ更新プログラムの情報を参照の上、早期に更新の展開をしてください。

実践の流れ

  1. 1この記事で作るもの：PC別の更新状況確認表と、未更新の人への連絡文
  2. 2先に知っておくこと：IPAの注意喚起が言っていること、言っていないこと
  3. 3手順①：確認表の枠を作り、台数分のPCを書き出す
  4. 4手順②：Windows Update画面で3つの状態を見分ける
  5. 5具体例：サンプル商会・佐藤さんの確認表と連絡文
