このページで確認すること

  • 国税庁が示した変更点を写した確認表（控除割合、2割特例の終了、簡易課税への移行措置、1億円の上限の4項目）
  • 取引先を3つの見方で分けた一覧
  • 税理士・税務署に聞く質問メモ
  • AIチャットを使う場合の指示文と、仕上がりを確かめる確認リスト

実践の流れ

  1. 1この記事で分かること：10月から変わった経過措置を、自社の取引に当てはめる前の確認表を作る
  2. 2国税庁が示した変更点を確認表に写す：控除割合・2割特例の終了・簡易課税への移行措置・1億円の上限
  3. 3取引先を3つの見方で分ける：登録番号の有無・免税事業者等・自社の2割特例の利用
  4. 4AIチャットに区分だけを貼って、質問メモと説明文の下書きを作る（実名・金額は貼らない）
  5. 5税理士・税務署に聞く質問メモを作る：自社の場合を確かめるための5つの質問
  6. 6確認リストと、うまくいかないときの次の行動
